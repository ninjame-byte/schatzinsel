# Prompts

Drei Prompts, um die Bearbeit- und Testbarkeit zu verbessern und das Spiel installierbar zu machen.

1. Teile die HTML Datei in mehrere Dateien auf, style, app und je eine js Datei für Aufgaben-Themen.

2. Weitere Aufteilung des js nach Karte
- Führe die weitere Aufteilung durch.
- Erstell eine kartentest.html, in der man alle Karten testen kann.
- Verschiebe die js und css Dateien in einen "res" Ordner.
- Gib mir das Ergebnis als v2.

3. PWA - Als App installierbar
- Mach den Kartentest spielbar.
- Mach eine PWA aus dem Spiel.
- Gib mir nur die geänderten Dateien als v3.
